# Zenzo Landing Page

The public landing page for **Zenzo**, a focused workspace for orchestrating AI agent teams, tools, and shared context.

## Deployment

This repository is published through **GitHub Pages**. The site is a dependency-light static page; its `index.html` includes the complete responsive layout, styles, and interactive squad simulation.

## Local preview

Open `index.html` directly in a browser, or serve the directory with any static-file server.

## Design direction

The page applies liquid-glass, bento-grid, morphic-navigation, and spotlight-card treatments inspired by [Kokonut UI](https://kokonutui.com/docs), recreated in standalone HTML, CSS, and JavaScript for portability.
