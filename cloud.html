Start securely

Set up Ox Alpha in three clear steps.

Zenzo Cloud is a secure handoff, not another provider account. You use it only to register the desktop that will use Ox Alpha.

01
Open Zenzo CloudSign in to the official Zenzo Cloud service from this page.
02
Register this desktopGenerate a revocable installation token for your own Zenzo device.
03
Connect from Zenzo SettingsPaste the one-time token in Zenzo → Settings → Zenzo Cloud.

The official Cloud address will appear here when the secure service is live.

What stays private

Your desktop never gets the provider key.

No shared API key in the app

Zenzo Cloud keeps the upstream credential server-side and never sends it to your computer.

One personal daily allowance

Each registered user receives a fresh daily quota; access fails safely when that allowance is exhausted.

Revocable device access

Your desktop receives an opaque installation token that can be disconnected without changing any provider account.
